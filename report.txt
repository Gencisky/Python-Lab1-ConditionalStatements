A2. Proqnoz:
16
16
None
Nəticə: Proqnozla eyni oldu. Sıra: b = show_square(4) çağırılanda funksiya daxilində
print(n * n) işləyir və ilk 16 çap olunur. Sonra print(a) ikinci 16-nı, print(b) isə None çap edir.
Əlavə sual: b niyə None alır? show_square heç nə qaytarmır (return yoxdur), Python belə
funksiyalar üçün avtomatik None qaytarır. square qiyməti return ilə geri verir, ona görə
nəticəni dəyişənə yazıb sonra istifadə etmək olur. show_square isə yalnız ekrana yazır,
qiymət proqrama qayıtmır.

A3. Proqnoz:

Nəticə: Proqnozla eyni oldu. add_item orijinal basket listini dəyişdi (milk əlavə olundu).
add_item_copy isə items[:] ilə kopya yaratdı, cheese yalnız kopyaya əlavə olundu və
basket-də cheese yoxdur.

TAPŞIRIQ 2
==================================================
Sual: Default qiyməti olan parametr niyə default-u olmayan parametrlərdən sonra yazılmalıdır?
Cavab: Python arqumentləri mövqeyə görə parametrlərə təyin edir. Default-lu parametr
əvvəl gəlsə, ondan sonrakı məcburi parametrə qiymətin necə veriləcəyi qeyri-müəyyən olar,
ona görə Python bunu SyntaxError kimi qəbul edir.

TAPŞIRIQ 5
==================================================
Çıxış:
[80, 100, 98, 100]
[70, 95, 88, 100]
[70, 95, 88, 100]
[80, 100, 98, 100]
Izah:
1-ci sətir: with_bonus bonus əlavə edilmiş YENİ list qaytarır, 95+10 və 100+10 100-ü
keçdiyi üçün 100 olur.
2-ci sətir: with_bonus orijinalı dəyişmir, ona görə scores əvvəlki kimi qalır.
3-cü sətir: add_bonus(scores[:], 10) funksiyaya listin kopyasını göndərir. Funksiya kopyanı
dəyişir, orijinal scores dəyişmir.
4-cü sətir: add_bonus(scores, 10) orijinal listi göndərir, funksiya onu yerində dəyişir.
scores[:] listin tam kopyasını (slice) yaradır, yəni yeni və ayrıca list alınır.
