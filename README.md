# Python Mini Projects

This repository contains three small Python programs created for a class assignment:

1. **BMI Calculator** (Body Mass Index)
2. **Zodiac Finder**
3. **Birthday Finder**

## Requirements

- Python 3.8 or higher

No external libraries are needed.

## Projects

### 1. BMI Calculator

Takes the user's height and weight, calculates their Body Mass Index, and prints which category the result falls into.

**Categories:**

| BMI Value | Category |
|-----------|----------|
| < 18.5 | Underweight |
| 18.5 – 24.9 | Normal |
| 25 – 29.9 | Overweight |
| ≥ 30 | Obese |
